# Presentazione fotografica – Lions Club Padova Tito Livio

Versione web dello slideshow del club. La pagina non contiene foto: le legge
dalla cartella condivisa del Google Drive del club (`Presentazione/FOTO L.C.
TITO LIVIO`, una sottocartella per anno lionistico) e i brani dalla cartella
`MUSICA`. Viene incorporata nel sito https://sites.google.com/view/lionspadovatitolivio

Per aggiornare l'elenco delle foto dopo aver aggiunto file su Drive va rigenerato
il catalogo in `index.html` (blocco `var M=...`).
