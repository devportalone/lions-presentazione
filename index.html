Importazione foto
Aggiungi foto da una cartella esterna
Per motivi di sicurezza il browser non può copiare direttamente file dal tuo PC alla chiavetta. Ho quindi aggiunto nella root il comando IMPORTA_FOTO.bat.
  1. Chiudi o riduci questa finestra.
  2. Apri la chiavetta USB.
  3. Fai doppio clic su IMPORTA_FOTO.bat.
  4. Scegli la cartella esterna da cui importare le foto.
  5. Lo script crea automaticamente le sottocartelle FOTO AAAA-AAAA in base alla data dello scatto e rigenera il catalogo.
  6. Riapri con AVVIA_SLIDESHOW.bat.
